Euer Arbeitsauftrag

Tina hat eine neue Musikbox. Stellt man eine Figur wie die Ente auf die Box, kann man Lieder hören. Oben auf der Box sind zwei Dreiecke. Aber wie funktioniert die Box genau?

  1. Probiert aus: Drückt die beiden Dreiecke, stellt die Ente auf die Box und nehmt sie wieder herunter, in verschiedenen Reihenfolgen.
  2. Beobachtet genau: Was macht die Box nach jeder Eingabe? Leuchtet das Licht? Spielt Musik? Wird es lauter oder leiser? Tragt es unten ins Protokoll ein.
  3. Welches Dreieck schaltet die Box ein? Was machen die Dreiecke, wenn die Box schon an ist?
  4. Was passiert, wenn niemand die Box bedient? Lasst die Box an und tut nichts. Mit „1 Minute nichts tun“ könnt ihr die Zeit vorspulen.
  5. Findet heraus: In welchen Zuständen kann die Box sein? Welche Eingaben und welche Ausgaben gibt es? Gebt jedem Zustand einen Namen.
  6. Zeichnet ein Übergangsdiagramm für die Musikbox in euer Heft.
Eingabe: Was ich mit der Box mache.
Ausgabe: Was die Box dann tut, zum Beispiel Licht oder Musik.
Zustand: In welcher Lage die Box gerade ist.
